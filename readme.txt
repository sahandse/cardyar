== Description ==
Cardyar provides a Persian-first foundation for bank-card payment instructions, payment records and receipt verification workflows.

== Installation ==
1. Upload the cardyar folder to /wp-content/plugins/
2. Activate the plugin.
3. Open کارت‌یار from WordPress admin.
