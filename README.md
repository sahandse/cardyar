# کارت‌یار

افزونه پرداخت کارت‌به‌کارت برای وردپرس و ووکامرس با رابط فارسی، مینیمال و مناسب فروشگاه‌های ایرانی.

## ویژگی‌ها
- تعریف چند کارت بانکی
- نمایش لوگوی بانک
- ثبت شماره مرجع تراکنش
- آپلود تصویر رسید
- وضعیت «در انتظار بررسی»
- تأیید/رد رسید توسط مدیر
- جلوگیری از شماره مرجع تکراری
- گزارش پرداخت‌ها
- آماده اتصال پیامک برای وضعیت پرداخت
